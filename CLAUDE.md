# Driver

Browser driving game on real-world terrain. Vanilla JS (ES modules), three.js (render),
cannon-es (physics), MQTT (multiplayer), Vite. No tests, no TS, no framework.

- `npm run dev` – local dev server; `npm run build` – sanity check (catches import/syntax errors).
- Deployed to GitHub Pages via `.github/workflows/pages.yml`.

## Layout
- `src/main.js` – composition root: creates every subsystem and wires them together.
- `src/config.js` – run mode, spawn origin, global tuning constants.
- `src/app/` – game orchestration: `mainLoop.js` (per-frame update order), `carManager.js`
  (local car spawn/respawn + remote roster), `input.js`, `collisions.js` (arcade responses,
  tunnel guards), `cameraFollow.js` + `cameraViews/` (one file per camera), `scoring.js`,
  `sceneSetup.js` (+ `colorGrade.js`: whole-frame grade in the reversed-depth copy pass - overcast mutes, cold air cools, hot air warms), `physicsSetup.js`. `frameBudget.js` = one shared per-frame streaming budget
  (`STREAMING_BUDGET_MS`) spent by tier: terrain is off-budget (must-have), then GAMEPLAY (near
  building collisions), then COSMETIC (rotated); streamers take a `deadline`. `gameplayLoad.js` =
  what startup/teleport await after terrain (overlay data + near buildings). `viewFrame.js` = this player's local frame (network frame is
  fixed at `ORIGIN`); `floatingOrigin.js` shifts the world back to near (0,0) every 2 km - anything
  keeping world-space positions between frames needs a `shiftOrigin(dx, dz)` registered there.
- `src/lib/` – subsystems:
  - World streaming: `terrain.js` (quadtree of elevation + aerial tiles, `TerrainManager`; worker
    fetch/decode + mesh building in `terrain/`; detail tiles carve OSM roads in as a raised bed, `terrain/roadBed.js`, with Heightfield physics), `buildings.js`
    (+ `buildingsCache.js` IndexedDB). Debug/gameplay overlays extend `tiles/vectorTileLayer.js`
    (fetch, bucketing, time-sliced builds, unload): `vectorLineLayer.js` → `streets.js` (K debug overlay; Settings road surface view = the same grip stripes as asphalt / gravel, road-bed roads only, dithered out at the radius from the car, painted markings (edge lines on higher classes, dashed centre on two-way roads, cleared at junctions found while decoding the tile), `ui/graphicsToggles.js`, mirrored with car dirt in the debug layers panel; debug Road polygons = their wireframe),
    `rivers.js`; `vectorPolygonLayer.js` → `waterAreas.js`, `builtUpAreas.js` (OSM landuse → built-up zone, `isBuiltUpAt`). `roadside.js` = knockable objects (trigger + tumbling debris in `knockable.js`, also used by the rally control scenery) placed from the streets layer's segments, one kind per file: `roadPosts.js` (edge posts), `streetLamps.js` (replace posts in built-up areas; night lighting in `streetLights.js`), `roadSigns.js` (chevron boards on curves/hairpins), `directionSigns.js` (arrow boards at junctions, rules in `config.js`, destinations from `places.js`; per-item meshes, HUD copy in `hud/directionSignHud.js`). `curbs.js` = 3 cm curbs along paved road-bed roads in built-up areas, broken where another road's stripe crosses (`streets.segmentsAt`); meshes per z18 chunk, ray-only static boxes near the car (`CURB_COLLISION_GROUP`: wheel rays hit them, no body collides). `tiles/openFreeMap.js` = vector tile
    fetch. `geo.js` = lat/lon ↔ tile ↔ local metres.
  - Vehicles: `car.js` = entry (`createCar`/`createRemoteCar`) + wheeled rig, helpers in `car/`
    (chassis body/inertia/hitboxes, wheel mesh, remote car, `rims.js` = rim library (holes / solid / spokes, count, convex / concave dish, face depth) picked per tyre compound group by descriptor `rims: { default, tarmac, loose, allRound, winter }`, overridable by the tyre setup `rim` / `rimColor`; geometry in `rimMesh.js`, `axles.js` = descriptor `axles` layout
    + shared-turn-centre steering for any axle count/duals, `trailer.js` = articulated trailer hitch;
    trailer wheels live in the same `wheelInfos`). Hover vehicles go to `chariot.js`,
    helpers in `chariot/` (hover repulsor, formation heading/coupling/tether, remote).
    `vehicleShared.js` = shared bits (material, name tag, reset helpers, remote shell).
    `wheeledVehicle.js` (custom raycast vehicle; ABS / traction control trim the brake / drive to config `ABS_GRIP_SHARE` / `TC_GRIP_SHARE` of static grip, descriptor `abs` / `tractionControl`, switched off from their dash lamps), `engine.js` (engine + gearbox, auto (sport / comfort / eco / cruise = eases off at the limit from `app/speedLimit.js`: motorway / trunk, built-up, open; `CRUISE_LIMITS_KMH`) or fully manual
    with neutral; optional turbo from descriptor `turbo` - boost lag scales torque, gauge in `hud/boostGauge.js`; descriptor `outsideTempGauge` = outside temp LCD in the speedo, `hud/outsideTempLcd.js`, + 10 min average consumption LCD beside it, `hud/fuelAverageLcd.js`; `gearGate.js` = H-gate + parallel range layout for the manual stick, `hud/gearstick.js` draws it; `gearboxWear.js` = gearbox health from over-rev engages and hits (`endImpact`), stretches shift/synchro time up to 5x, fixed by `repairDamage()`), `fuel.js` (tank per descriptor `fuelTankL`/`fuelType`, burns by `engine.throttle`, `loadFraction` + rpm, adds fuel mass to the chassis), `engineHeat.js` (block/coolant/oil temps from load, rpm and airflow; thermostat + fan; descriptor `radiator`/`coolantL`; coolant level with leaks from nose hits (`collisions.js` `endImpact`) and boil-over, oil level (burn + sump leaks from underbody hits, `endImpact().under`, taken first by a skid plate on descriptors with `skidPlate` (rally cars); low oil starves the oil flow and overheats it), limp-mode `powerFactor` into `engine.js`; fixed with shocks + lamps by `vehicle.repairDamage()` (reset); outside air = `weather.js` `getAirTempC()`), `airDrag.js`,
    `surfaceCompounds.js` (also per-surface tyre wear / puncture / wet / dirt factors), `terrainSurface.js`. `tyres.js` = tread wear
    (grip), rim-strike punctures and running on the rim (smaller radius, drag, toe pull, no sidewall), broken rims from
    harder strikes (surface `rimBreakMultiplier`, tarmac highest; squashed oval (mesh + hub drop twice a revolution); any new tyre / spare = new wheel), per-wheel
    fields used by `wheeledVehicle.js`; reset and rally service points (`tyres: true` point types) fit fresh tyres.
    `tyres/compounds.js` = tyre types (grip per surface, wear, temp window, wet/dirt traits; descriptor `tyreCompound` = stock),
    `tyres/condition.js` = tread temperature, dirt, wetness (floor = `weather.js` `getWetness()`),
    `tyres/setup.js` = player setup { compound, rimSize, width, profile } around stock (descriptor `tyreSizes`), applied
    to the descriptor by `createCar`. `garage.js` = per-mode, per-vehicle paint + tyre setup (mode-wide save field);
    picked in `ui/tyreSetupPicker.js` (lobby, rally picker, debug picker, free roam / editor Garage window `ui/garageDialog.js`; both pickers share the car step `ui/carSelect.js` = car + paint + tyres from the HUD's Garage button (where Settings used to be; Settings now only via the main menu), rally `ui/tyreServiceDialog.js` = removed set per wheel + 3D views of its dirtiest tyre and the pick, `ui/tyrePreview.js`; the rally picker leaves tyres to service points, a single stage picks them there). Rally spare wheels: `spareTyres.js` (count, mass via `fuel.setCargoKg`, stage penalty), picked in `ui/spareTyresPicker.js` (rally picker + tyre service, garage field `spares`), fitted by `vehicle.fitSpareTyre(i)` as a rally field fix. Floating part buttons: `app/partCallouts.js` (anchors on the stopped car) + `hud/repairCallouts.js`. Free roam: `app/roadsideRepair.js` puts one on each damaged part (flat/worn tyre, shock, radiator / coolant, sump / oil, lamp, gearbox, exhaust, low fuel) and replaces it on a click; there resets and teleports don't repair (carManager `repairOnReset`) and an empty tank stays empty with no power (`refillWhenEmpty`).
    `brakes.js` = disc / drum per wheel (descriptor `brakes: { front, rear, pads }`, `{ discMm, vented }` or `{ drumMm }`), heated by the brake work `wheeledVehicle.js` adds to `wheel.brakeWorkJ`, cooled by air / water; pad fade, warp from overheating, cracks from fast cooling (wading in hot); front / rear pipe circuits + fluid reservoir, pipes cracked by underbody hits (`endImpact().under`, small chance) leak; scales `applyBrakes` in `car.js`; meshes + glow `car/brakeMesh.js`, wading steam `brakeSteam.js`, debug BRAKES panel `hud/brakeHud.js`, dash lamp, service / field / roadside repairs; its own car state field `brakes` (not `damage`), repairDamage() still fixes it.
    `shocks.js` = per-wheel shock health, worn by bump-stop strikes; lowers damping and spring rate. `lampDamage.js` =
    broken head/tail lamps per side from end hits (`endImpact`); `headlights.js` darkens them and scales the pools. `exhaustDamage.js` = exhaust health from tail / floor hits and ground scraping; at 0 it falls off (-20% power via `engine.powerFactor`, raw engine sound in `audio/engine.js`); descriptor `breakableExhaust: false` = no exhaust system to damage (postapo cars); `exhaustPipes.js` = generic silencer + tailpipe per low rear `exhaustTips` entry that sags and swings when worn, scrapes the ground estimated from the wheel contacts (sparks, rim-grind sound; no hitbox) and drops off as `knockable.js` debris; geometry builders tag modelled tailpipes `userData.exhaust = true` so they ride on it (stacks / side pipes: give `exhaustTips` a `dir` that isn't rearward, then no generic pipe). All of these (and gearbox health) saved as car state `damage`. `bodyDirt.js` = body dirt level (flung from dirty tyres, slow road grime, rinsed by wading, washed by hard reset / `makeNew`), drawn by patching the paint shader; also in `damage`, toggled in Settings > Graphics.
  - `vehicles/` – one descriptor file per vehicle (tuning data) + `geometry/` (mesh builders).
    Body paint = `geometry/paint.js` `createPaintMaterial`; a paint value is 0xRRGGBB plus the `METALLIC_PAINT` flag bit (saves, net, `defaultColor`). Register new vehicles in `vehicles/index.js`. Ids are `C001` (wheeled) / `S001` (hover), never reused; the display
    name lives only in `vehicles/names.js`. Pre-scheme ids map in `vehicles/legacyIds.js` (`getVehicle` accepts them,
    `lib/vehicleIdMigration.js` rewrites stored data after the cloud restore, the worker renames board entries).
  - Effects: `tireSmoke.js`, `terrainDust.js`, `wheelDebris.js` (leaves / grass / clods / stones from sliding tyres; it, wheel dust and wet spray toggle in the Graphics layers), `wetSpray.js` (droplets off rolling tyres on wet ground, by tyre `wetness` and surface), `bodyDust.js`, `exhaustFlames.js`

    `particles/puffPool.js`), `rimSparks.js` (tyre-pop smoke + spark burst, sparks from flat rims on road/rock; streaks

    `headlights.js` = cosmetic lamps + front and rear ground spotlights (brake/reverse on the rear; on/off in `app/headlightSwitch.js`); geometry builders tag lamp
    materials with `userData: { lamp: 'head' | 'tail' | 'fog' }`.

    only the start values; `onWeatherChange`). `app/weatherFeed.js` = Open-Meteo hourly forecast at the car, read at the simulated
    time (`daylight.getTimeMs`), refetched by distance / age; sets temp + cloud preset (`classifyClouds`). `hud/weatherDebug.js` =
    debug panel readout, road Live / Dry / Damp / Wet (Live = `weatherFeed.setLiveWetness`: the rally wetness model, seeded from the forecast's last 24 h at the car, then stepped by the weather now with the debug overrides; wetness: tyre wet grip + wet road look in `streets.js`, surface view only), a

Fog: `getVisibilityM()` (forecast `visibility`, capped on WMO fog codes by `rallyWeather.js` `visibilityFor`; rally snapshots carry it; debug Fog override) or the rain's haze if thicker (mist at heavy rain) → `app/weatherFog.js` (run by `daylight.js`): linear fog from the camera in `scene.fog` and the terrain haze (`terrain.js` `setFogFar`, `applyFogVeil` for unhazed cirrus), sky grey / sun dim / stars / colour grade by its share.

## Conventions
- Modules export `createX(...)` factories returning plain objects, or `XManager` classes for
  tile streamers (`update`, `recenter`, `getStats`, `isTileLoaded`).
- Physics axes: x right, y up, z forward. Collision groups exported from `terrain.js` / `buildings.js`.
- Ground draw order: `terrain.js` `GROUND_RENDER_ORDER` (terrain → road surface view → contact shadows, the last two depth-biased without depth writes); everything else stays at renderOrder 0 so it draws over them.
- Per-vehicle values come from the descriptor with a module-level default (`descriptor.x ?? DEFAULT_X`).
- Keep comments short: one line of *why* for non-obvious choices; no history or cross-file narration.
- Before implementing, ask clarifying questions whenever a request is ambiguous or has
  several reasonable interpretations (behaviour, layout, tuning values, which vehicles).
  Don't guess on design decisions the user should make.

## Token hints
- `README.md` is user-facing docs with deep background; usually skip it.
- Largest files: `terrain.js` (~1300 lines), `app/rally/rallySession.js`, `main.js`, `rally/controlScenery.js` –
  grep for the function first and read only that range.
- Comment-only edits can be verified by building and comparing the hash of `dist/assets/*.js`
  (the minifier strips comments; mask the `YY.MM.DD-HH.MM` build timestamp first).
