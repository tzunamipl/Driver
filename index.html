About

Driver is a browser driving game on real-world terrain: elevation, aerial imagery, roads and buildings streamed for anywhere on Earth.

The game is still in development, so expect rough edges, missing features and frequent changes.

It is coded with the help of AI assistants: GitHub Copilot and Claude.
